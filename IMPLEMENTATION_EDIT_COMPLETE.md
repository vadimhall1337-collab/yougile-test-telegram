# ✅ Реализация редактирования задач

## Статус: ЗАВЕРШЕНО

Функционал редактирования задач полностью реализован и интегрирован в бота.

---

## 📋 Что реализовано:

### 1. **DTO (Data Transfer Objects)**
**Файл:** `bot/yougile/dto/tasks.py`

Расширены классы для поддержки редактирования:
- `CreateTaskDto` — добавлено поле `deadline`
- `UpdateTaskDto` — добавлены поля:
  - `description: Optional[str]`
  - `deadline: Optional[date]`

### 2. **Клавиатуры**
**Файл:** `bot/keyboards/inline/tasks.py`

Добавлены новые функции:
- `get_task_detail_keyboard()` — обновлена, добавлена кнопка "✏️ Редактировать"
- `get_edit_menu_keyboard(task_id)` — меню выбора поля для редактирования
- `get_cancel_edit_keyboard(task_id)` — кнопка отмены редактирования

Новые CallbackData фабрики:
- `TaskActionCallback` — добавлен action `"edit"` и `"cancel_edit"`
- `EditFieldCallback` — для выбора поля (title, description, deadline)

### 3. **FSM States**
**Файл:** `bot/states/edit.py`

Создана группа состояний `EditTaskState`:
- `waiting_for_field` — ожидание выбора поля
- `waiting_for_new_title` — ожидание нового названия
- `waiting_for_new_description` — ожидание нового описания
- `waiting_for_new_deadline_date` — ожидание новой даты дедлайна

### 4. **Сервис**
**Файл:** `bot/services/task_edit.py`

Класс `TaskEditService` с методами:
- `get_task(task_id)` — получение задачи
- `update_title(task_id, new_title)` — обновление названия
- `update_description(task_id, new_description)` — обновление описания
- `update_deadline(task_id, new_deadline)` — обновление дедлайна

Все методы логируют изменения через structlog.

### 5. **Handlers**
**Файл:** `bot/handlers/edit.py`

Создан `edit_router` с обработчиками:

#### Callback Query Handlers:
1. **Начало редактирования** (`action == "edit"`)
   - Показывает меню выбора поля
   
2. **Выбор поля** (`EditFieldCallback.filter()`)
   - title → переход в состояние ожидания названия
   - description → переход в состояние ожидания описания
   - deadline → переход в состояние ожидания даты

3. **Отмена** (`action == "cancel_edit"`)
   - Возвращает карточку задачи
   - Очищает FSM state

#### Message Handlers:
1. **Новое название** (`waiting_for_new_title`)
   - Принимает текст
   - Валидирует (не пустое)
   - Обновляет задачу
   - Показывает обновленную карточку

2. **Новое описание** (`waiting_for_new_description`)
   - Принимает текст
   - Специальное значение "-" для удаления описания
   - Обновляет задачу
   - Показывает обновленную карточку

3. **Новый дедлайн** (`waiting_for_new_deadline_date`)
   - Парсит формат ДД.ММ.ГГГГ
   - Валидирует дату
   - Обновляет задачу
   - Показывает обновленную карточку

### 6. **Интеграция в main.py**
- Импорт `edit_router`
- Добавление роутера в `dp.include_routers()`
- Создание `TaskEditService`
- Добавление сервиса в `workflow_data` для DI

## 🎯 Пользовательский сценарий:

```
1. Пользователь открывает задачу из списка "Сегодня"
   ↓
2. Нажимает "✏️ Редактировать"
   ↓
3. Выбирает поле:
   - 📝 Название
   - 📄 Описание  
   - 📅 Дедлайн
   ↓
4. Вводит новое значение
   ↓
5. Получает подтверждение и обновленную карточку
```

Или отмена в любой момент через кнопку "❌ Отмена".

---

## 🔧 Технические детали:

### Валидация данных:
- **Название:** не может быть пустым
- **Описание:** можно удалить отправкой "-"
- **Дедлайн:** строгий формат ДД.ММ.ГГГГ, проверка корректности даты

### Кэширование:
- При обновлении задачи автоматически инвалидируется кэш:
  - Детали задачи
  - Списки задач на сегодня
  - Поиск задач

### Логирование:
Все изменения логируются через structlog:
- Task title updated
- Task description updated  
- Task deadline updated
