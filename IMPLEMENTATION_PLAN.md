# План реализации функционала Telegram-бота для YouGile

## Приоритеты (1-5):

### 1. Редактирование задач ✅ В ПРОЦЕССЕ
**Файлы для создания/изменения:**
- `bot/keyboards/inline/tasks.py` — добавить клавиатуру редактирования
- `bot/states/task_edit.py` — FSM состояния для редактирования
- `bot/handlers/edit.py` — обработчики команд редактирования
- `bot/services/task_edit.py` — сервис логики редактирования
- `bot/yougile/dto/tasks.py` — расширить UpdateTaskDto (deadline)
- `bot/yougile/endpoints/tasks.py` — проверить поддержку deadline

**Функционал:**
- Изменение названия задачи
- Изменение описания
- Изменение дедлайна
- Отмена редактирования

---

### 2. Создание подзадач
**Файлы для создания:**
- `bot/states/subtask_creation.py` — FSM состояния
- `bot/handlers/subtasks.py` — обработчики
- `bot/services/subtask_creation.py` — сервис
- `bot/keyboards/inline/tasks.py` — кнопка "➕ Добавить подзадачу"

**Функционал:**
- Добавление подзадачи к родительской задаче
- Привязка к той же колонке или доске
- Уведомление о создании

---

### 3. Комментарии к задачам
**Файлы для создания:**
- `bot/yougile/endpoints/comments.py` — эндпоинт API
- `bot/yougile/dto/comments.py` — DTO для комментариев
- `bot/repositories/comments.py` — репозиторий с кэшированием
- `bot/handlers/comments.py` — обработчики
- `bot/keyboards/inline/comments.py` — клавиатуры
- `bot/states/comment_add.py` — FSM для добавления

**Функционал:**
- Просмотр списка комментариев задачи
- Добавление нового комментария
- Удаление своих комментариев (опционально)

---

### 4. Быстрые действия
**Файлы для изменения:**
- `bot/keyboards/inline/tasks.py` — добавить inline-кнопки в список задач
- `bot/handlers/today.py` — обработчики быстрых действий

**Функционал:**
- Кнопка "✅" рядом с каждой задачей в списке (выполнить без открытия)
- Кнопка "🕒" рядом с каждой задачей (отложить без открытия)
- Подтверждение действия через alert

---

### 5. Уведомления об изменениях (Polling)
**Файлы для создания:**
- `bot/services/yougile_polling.py` — сервис polling'а изменений
- `bot/scheduler/polling_scheduler.py` — планировщик
- `bot/handlers/notifications.py` — обработчики уведомлений

**Функционал:**
- Периодическая проверка изменений в задачах (каждые 30-60 сек)
- Сравнение с кэшированными данными
- Отправка уведомлений пользователю об изменениях:
  - Изменение статуса задачи
  - Новые комментарии
  - Изменение дедлайна
  - Новые подзадачи

---

## Порядок реализации:

1. **Редактирование задач** (текущий приоритет)
2. **Быстрые действия** (простая фича, даст быстрый результат)
3. **Создание подзадач** (логичное продолжение работы с задачами)
4. **Комментарии** (требует нового эндпоинта API)
5. **Уведомления** (самая сложная часть, требует polling)

---

## Технические заметки:

### YouGile API v2 endpoints:
- `GET /tasks/{id}` — получение задачи
- `PUT /tasks/{id}` — обновление (title, columnId, completed, archived, deadline?)
- `POST /tasks` — создание
- `GET /task-list` — список задач с фильтрацией
- `GET /columns` — список колонок
- `GET /comments?taskId={id}` — комментарии (нужно проверить)
- `POST /comments` — добавить комментарий (нужно проверить)

### Rate Limiting:
- 50 запросов в минуту уже реализован в `YouGileClient`
- Нужно учитывать при polling'е

### Кэширование:
- Использовать `CacheService` для всех запросов
- Инвалидировать кэш при мутациях
- TTL: детали задачи — 5 мин, списки — 2 мин, колонки — 12 часов
