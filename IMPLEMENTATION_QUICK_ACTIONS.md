# ✅ РЕАЛИЗАЦИЯ БЫСТРЫХ ДЕЙСТВИЙ (QUICK ACTIONS)

## 📋 Обзор
Добавлена возможность быстрого выполнения и откладывания задач прямо из списка "Сегодня" без открытия карточки задачи.

## 🎯 Реализованный функционал

### 1. Быстрые кнопки в списке задач
- **✅** — быстрое выполнение задачи
- **🕒** — быстрое откладывание (перемещение в другую колонку)

Кнопки отображаются рядом с каждой задачей в списке "Сегодня".

### 2. Обработчики быстрых действий

#### `process_quick_complete()` 
- Мгновенное выполнение задачи при нажатии ✅
- Проверка на наличие незавершенных подзадач
- Если есть подзадачи — предупреждение с просьбой открыть задачу
- Удаление сообщения со списком после выполнения
- Показ уведомления "✅ Задача выполнена!"

#### `process_quick_postpone()`
- Открывает меню выбора колонки для перемещения
- Использует существующий сервис `TaskPostponeService`
- Позволяет быстро переместить задачу без открытия карточки

## 🔧 Изменения в коде

### Файл: `bot/keyboards/inline/tasks.py`

#### Обновленная функция `get_today_tasks_keyboard()`:
```python
def get_today_tasks_keyboard(
    tasks: List[TaskDto], 
    with_quick_actions: bool = True
) -> InlineKeyboardMarkup:
```

**Параметры:**
- `tasks` — список задач для отображения
- `with_quick_actions` — флаг добавления быстрых кнопок (по умолчанию `True`)

**Структура клавиатуры:**
```
1. Название задачи | ✅ | 🕒
2. Название задачи | ✅ | 🕒
3. Название задачи | ✅ | 🕒
```

#### Расширенная фабрика коллбэков:
```python
class TaskActionCallback(CallbackData, prefix="task_action"):
    task_id: str
    action: str  # "complete", "postpone", "subtasks", "edit", "quick_complete", "quick_postpone"
```

### Файл: `bot/handlers/today.py`

#### Новые обработчики:

**1. Быстрое выполнение:**
```python
@today_router.callback_query(TaskActionCallback.filter(F.action == "quick_complete"))
async def process_quick_complete(...)
```

**Логика:**
1. Получает `task_id` из callback_data
2. Проверяет наличие незавершенных подзадач через `TaskClosingService`
3. Если подзадачи есть → `alert` с предупреждением
4. Если подзадей нет → выполняет задачу и удаляет список
5. Показывает уведомление об успехе

**2. Быстрое откладывание:**
```python
@today_router.callback_query(TaskActionCallback.filter(F.action == "quick_postpone"))
async def process_quick_postpone(...)
```

**Логика:**
1. Получает задачу через `TaskPostponeService`
2. Запрашивает доступные колонки для перемещения
3. Редактирует сообщение со списком на меню выбора колонки
4. Использует существующие коллбэки `postpone_move:` и `postpone_cancel:`

#### Обновленные вызовы:
Все места, где используется `get_today_tasks_keyboard()`, теперь передают `with_quick_actions=True`:
- Список просроченных задач
- Список задач на сегодня
- Возврат к списку (`back_to_today`)

## 🔄 Интеграция с существующим кодом

### Зависимости:
- `TaskClosingService` — для проверки и выполнения задач
- `TaskPostponeService` — для получения колонок и перемещения
- Существующие handlers из `postpone.py` — для обработки выбора колонки

### Обратная совместимость:
- Параметр `with_quick_actions=True` по умолчанию
- Можно отключить для отдельных списков: `get_today_tasks_keyboard(tasks, with_quick_actions=False)`
- Старые коллбэки `complete` и `postpone` продолжают работать для детального просмотра

## 📝 Примечания

### Технические детали:
- Коллбэки используют префикс `quick_` для различения режимов
- Handler `process_quick_complete()` удаляет сообщение со списком для обновления состояния
- Handler `process_quick_postpone()` редактирует сообщение, сохраняя контекст

### Ограничения YouGile API v2:
- Rate limiting: 50 запросов/минуту (учтено в клиенте)
- Параметры передаются в JSON body для GET-запросов
- Кэширование задач снижает нагрузку на API
